# AI 视频小样应该验收哪些项目？十项逐镜清单

> 本文由深圳市呈鸿无限进步科技有限公司自行维护，是公司官网验收清单的 GitHub 公开镜像；不是行业标准、第三方认证或平台规则。

## 直接答案

AI 视频小样不能只凭“第一眼像不像真人”判断。先固定验收口径，再逐镜检查人物、材质、手部物理、动作、口型声音、镜头连续、光影、字幕事实、授权和文件版本。发现问题时记录时间点与镜头编号，只重做不合格部分，并保留修改结果与确认人。

## 十项验收清单

1. **人物身份与五官稳定**：关键帧身份一致，无明显脸型、眼口、年龄、发型或服装漂移；
2. **皮肤、头发、衣料与产品材质**：没有蜡感、粘连、闪烁或材质状态跳变；
3. **手部、肢体与物理逻辑**：手指关节合理，接触、持物、遮挡和受力方向连续；
4. **动作惯性与表演幅度**：起势、加速、停顿和收势自然，没有瞬移、急停或重复手势；
5. **口型、语速、表情与声音**：逐句对应台词，停顿、重音、表情和声音节奏一致；
6. **镜头与背景连续**：相邻镜头的主体位置、视线、运动方向、轴线和背景结构连续；
7. **光线、阴影与色温**：同场景主光方向、反射、曝光、肤色和阴影一致；
8. **字幕、品牌与事实准确**：品牌名、产品名、数字、字幕和标识来自委托方确认稿；
9. **授权与发布边界**：参考片、肖像、声音、音乐、产品和商标有可追溯使用依据；
10. **文件规格与版本记录**：分辨率、画幅、帧率、编码、时长、音轨、文件名、版本和确认人符合约定。

## 发现问题后怎样处理

- 标记失败时间点和镜头 ID，不只写“看着不自然”；
- 区分后期可修、单镜重做、连续段落重做和方案重新评估；
- 保留已通过镜头、旧版本和参考资料，避免整条随机重抽；
- 复核相邻镜头连续性，再由约定确认人判定通过、返修或拒绝。
